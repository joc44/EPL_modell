# Archived Premier League Data

These five original CSVs are from [football-data.co.uk](https://www.football-data.co.uk/englandm.php), league code `E0`.

| File | Season | Provider URL |
|---|---|---|
| `E0_2021_2022.csv` | 2021/22 | https://football-data.co.uk/mmz4281/2122/E0.csv |
| `E0_2022_2023.csv` | 2022/23 | https://football-data.co.uk/mmz4281/2223/E0.csv |
| `E0_2023_2024.csv` | 2023/24 | https://football-data.co.uk/mmz4281/2324/E0.csv |
| `E0_2024_2025.csv` | 2024/25 | https://football-data.co.uk/mmz4281/2425/E0.csv |
| `E0_2025_2026.csv` | 2025/26 | https://football-data.co.uk/mmz4281/2526/E0.csv |

Raw provider bytes are preserved. The language conversion affects project text, not dates, scores, team names or other provider data. The model uses `Date`, `HomeTeam`, `AwayTeam`, `FTHG` and `FTAG`. Dates are day/month/year.

Keep these archived files when reproducing the experiment; later provider corrections may produce different downloads. The source is attributed here and in the project documentation; no ownership of the provider's data is claimed.
